# Service Request Management System

A web-based Service Request Management System developed using HTML, CSS, JavaScript, Spring Boot, and MySQL.

## Features

### User Features

* Submit a service request
* Receive a request tracking link after submission
* View request details
* Track request status
* View request information

### Admin Features

* Admin login
* View all service requests
* Search service requests
* Filter requests by status
* Filter requests by priority
* Filter requests by category
* Filter requests by assigned support person
* View complete request details
* Change request status
* Change request priority
* Assign requests to support people
* Add internal notes
* View internal notes
* View request statistics

## Database Setup

The application uses MySQL as its database.

### 1. Create the Database

Open MySQL or phpMyAdmin and run:

```sql
CREATE DATABASE service_desk;
```

The database name must be:

```text
service_desk
```

### 2. Database Tables

The Spring Boot application uses JPA entities to manage the database tables.

The main entities are:

* Request
* Note
* SupportPerson
* Admin

Hibernate automatically creates or updates the required tables using:

```properties
spring.jpa.hibernate.ddl-auto=update
```

Therefore, after creating the `service_desk` database, the required tables will be created automatically when the Spring Boot application starts.

### 3. Support People

The application uses a `support_people` table for assigning service requests to support staff.

The table contains:

* `id`
* `name`
* `email`

Current support people data:

| id | name  | email                                         |
| -- | ----- | --------------------------------------------- |
| 1  | Admin | [admin@example.com](mailto:admin@example.com) |
| 2  | Jibon | [rahim@example.com](mailto:rahim@example.com) |
| 3  | Yusra | [karim@example.com](mailto:karim@example.com) |

If the `support_people` table has already been created by Hibernate, the support people can be inserted using:

```sql
INSERT INTO support_people (name, email)
VALUES
('Admin', 'admin@example.com'),
('Jibon', 'rahim@example.com'),
('Yusra', 'karim@example.com');
```

The `id` field is automatically generated by the database.

## Backend Configuration

The backend is a Spring Boot application located at:

```text
Backend/service-desk/
```

The database configuration is stored in:

```text
Backend/service-desk/src/main/resources/application.properties
```

The application uses environment variables for database credentials.

The configuration is:

```properties
spring.application.name=service-desk

spring.datasource.url=jdbc:mysql://localhost:3306/service_desk

spring.datasource.username=${DB_USERNAME:root}

spring.datasource.password=${DB_PASSWORD:}

spring.jpa.hibernate.ddl-auto=update

spring.jpa.show-sql=true

spring.jpa.properties.hibernate.format_sql=true

server.port=8080
```

The actual MySQL password should NOT be stored in the source code or committed to GitHub.

## Setting Database Credentials

### Windows PowerShell

Before starting the Spring Boot application, set the MySQL credentials:

```powershell
$env:DB_USERNAME="root"
$env:DB_PASSWORD="your_mysql_password"
```

Replace `your_mysql_password` with the password of your local MySQL installation.

For example:

```powershell
$env:DB_USERNAME="root"
$env:DB_PASSWORD="mypassword"
```

If your MySQL root account does not have a password:

```powershell
$env:DB_USERNAME="root"
$env:DB_PASSWORD=""
```

## Troubleshooting

### Backend Does Not Start

Check that:

* Java 26 is installed.
* MySQL is running.
* The `service_desk` database exists.
* The MySQL username is correct.
* The MySQL password is correct.
* Port `8080` is not being used by another application.

Check the Java version:

```powershell
java -version
```

### Database Connection Error

Make sure the environment variables are correctly configured:

```powershell
$env:DB_USERNAME="root"
$env:DB_PASSWORD="your_mysql_password"
```

Also make sure MySQL is running and the `service_desk` database exists.

### Frontend Cannot Connect to Backend

Make sure the Spring Boot backend is running:

```text
http://localhost:8080
```

Then reload the frontend page.

Also check that the API URLs configured in the frontend JavaScript files point to the correct backend address.
